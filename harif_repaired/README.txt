# دوري الحريف — نسخة مُصلحة

تم إصلاح حزمة الويب وتجهيز مشروع Android Wrapper.

## الإصلاحات
- توحيد أسماء الأيقونات إلى `icon-192.png` و`icon-512.png`.
- إنشاء نسخة 192×192 من الأيقونة المرفوعة.
- تحديث Service Worker إلى cache v2.
- تجهيز مشروع Android باسم التطبيق `دوري الحريف`.
- التطبيق يعمل RTL ويحفظ بياناته عبر localStorage.
- نسخة Android تحمل ملفات التطبيق داخل APK، لذلك لا تحتاج استضافة للموقع نفسه.

## بناء APK
افتح مجلد `android` في Android Studio ثم Build > Build APK(s).

ملاحظة: بيئة العمل الحالية لا تحتوي Android SDK/Gradle، لذلك تم تجهيز المشروع لكن لم أستطع إخراج APK ثنائي من داخل هذه البيئة.
